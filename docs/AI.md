# AI 家教：架構、查核規則與使用限制

## 流程

```
已驗證資料（core/providers + core/quality）
  → 分析模組（core/analysis/technical.py）：計算指標，把每個數字登錄成「事實」（Fact）
  → 規則式解說：依固定規則產生（永遠可用，不需要 AI）
  → AI 家教（選用，core/ai/tutor.py）：只拿到事實清單，回傳結構化 JSON
  → 查核（core/ai/guard.py + tutor.review）：通過才顯示，不通過就只顯示規則式解說
```

## 查核規則

AI 的回答只要有下列任何一項，就**整段不顯示**：

| 檢查 | 規則 |
|---|---|
| 數字 | 每個數字都必須等於某個事實「四捨五入到它寫出的位數」的結果（允許股／張、元／億、比例／百分比換算）。例如事實是 2,590，寫 2,590 可以，寫 2,600 不行 |
| 日期 | 每個日期（2026-10-16、11/26）都必須出現在事實清單裡 |
| 引用 | `facts_used` 裡列出的事實 id 必須都存在 |
| 用語 | 不可以出現買賣建議、目標價、停損價、保證獲利、「一定會漲／跌」 |
| 允許的常數 | 指標參數與門檻（14、20、60、70、30、80…）、步驟編號、年份 |

無法取得的資料會列在事實清單的 `unavailable`，AI 被要求明確說「目前無法取得」。

畫面上，AI 的回答分成三部分顯示：**✅ 已驗證事實**（引用的資料表）、**🤖 AI 解讀**、**❓ 不確定／資料不足**。

## 抽換 AI 廠商

`core/ai/llm.py` 定義了 `LLMBackend` 介面。目前的實作是 `GeminiBackend`（官方 SDK `google-genai`）。要換廠商時，新增一個 backend，並修改 `get_backend()` 即可。業務邏輯不直接呼叫任何 SDK。

## Google Gemini 使用限制（依 2026-11-27 查閱的官方文件）

- **模型：** 預設 `gemini-3.5-flash-lite`（官方標示為穩定版），可以用 `GEMINI_MODEL` 改成其他模型。
- **頻率：** 官方沒有公布這個模型的免費額度數字。程式裡保守設定為每 4 秒 1 次、每天 200 次，整個伺服器共用（`core/net.py`）。
- **免費方案的資料使用：** 官方條款說明，免費方案送出的內容會被 Google 用來改善產品，也可能有人工審閱，並要求不要送出敏感或個人資料。本系統送出的只有股票的公開市場資料與指標，不會送出使用者的個人資料。
- **用途限制：** 條款寫明服務供「專業或商業用途，不供一般消費者使用」、使用者須年滿 18 歲，並且不可依賴它作為財務建議。**把免費方案開放給一般大眾使用，可能不符合條款。** 公開上線前請評估：改用付費方案、限制只有自己使用（例如加密碼），或只在本機使用。
- **地區：** 必須在官方支援的地區使用。台灣是否在支援地區內，請以官方的 available-regions 頁面為準（尚未確認）。
